# PROTOTIPO-SISTEMA-MOTORIZADO-DE-LANZAMIENTO-CON-EL-FIN-DE-PROTEGER-CULTIVOS-EN-LA-CIUDAD-DE-BOGOTA
Este prototipo tipo catapulta automatiza la expulsión de cascarilla de arroz mediante un microcontrolador ESP32 y motores, creando una barrera física que frena al caracol de jardín sin químicos tóxicos en huertas de Bogotá.
